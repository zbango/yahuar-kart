# Yahuar Kart — prototipo 3D

Juego arcade de carreras de karts con Three.js, TypeScript y Vite.

## Ejecutar

Requiere Node.js 20.19+ o 22.12+.

```bash
npm install
npm run dev
```

Abre http://localhost:5173.

## Controles

- W / flecha arriba: acelerar
- S / flecha abajo: frenar o marcha atrás
- A / flecha izquierda: girar a la izquierda
- D / flecha derecha: girar a la derecha
- R: reiniciar

## Compilar

```bash
npm run build
npm run preview
```

No requiere modelos ni texturas externas.
